# diagnostics

Output from `tools/Recon.lua` goes here.

```
copy "<matcha workspace>\recon.txt" diagnostics\recon.txt
```

The capture is a few hundred KB of action surfaces (prompts, click detectors, tools, GUI
text, values, nearby parts) — not the 64k-instance tree. It is the difference between
guessing at cooking and writing the restaurant module against real names.

Commit it. It is game data, contains no personal information, and the pre-commit hook still
scans it.
